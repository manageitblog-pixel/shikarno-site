## Бренд (не змінювати без рішення власника)
- Кольори: жовтий `#FFD60A`, градієнт `#7C5CFF → #FF4F8B`, бірюзовий `#4CF2FF`, фон `#0B0A1C → #1A1240`.
- Шрифти: Montserrat 800/900 (заголовки), Golos Text (текст).
- Ведучий — робот Байт (SVG, настрої talk / happy / judge / shock). Логотип «ШІкарно» — плашка «ШІ» жовтим.

## Обкладинки
- Стандарт — **v4** (`Thumb4` / `Thumb4Wide`, `finalize.py --style v4`): плашка серії жовтим, 2–3 логотипи сервісів, великий текст з одним акцентним словом у жовтій плашці (`*слово*`), 1–3 «ключі»-пігулки, Байт з емоцією, діагональний фон двох кольорів.
- Правила: один об'єкт у фокусі; текст ≤ 6 слів і не дублює назву, а додає інтригу; читається розміром з ніготь; логотипи — лише реальних сервісів з ролика.
- Shorts: у стрічці мобільного застосунку обкладинка = **кадр 0**. Тому кадр 0 — плашка серії, великий `hook` з ключовим словом кольором рубрики, Байт; кадри 0–3 нерухомі.
- Довгі (16:9): Thumb4Wide; CTR міряти лише через YouTube Studio «Test & compare» (API CTR не віддає).

## Графіка в роликах
- Тір-лист: колонки «Погано / Добре / Найкраще» (червоний / жовтий / зелений обвід), рядки з підписами, хук зверху з акцентом.
- Джерела в довгих: скрін першоджерела з підсвіченою рамкою (`hl`), плашка «ДЖЕРЕЛО», домен.
- Субтитри: великі, жирні, активне слово — акцентним кольором.

## Сайт
