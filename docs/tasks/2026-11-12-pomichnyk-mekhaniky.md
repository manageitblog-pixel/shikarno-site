# «Твій ШІ-помічник за 10 хвилин» — механіки (12.11.2026, на погодження власнику)

Тестові набори: /pomichnyk-vchytel/, /pomichnyk-fop/ (noindex).

## 1. Звідки людина приходить
- Shorts/довгі: «Напиши боту Байта слово ПОМІЧНИК — збере ШІ під твою роботу» (опис, закріп, кінцівка).
- Сайт: банер на статтях за професіями → сторінка набору.
- Telegram-канал: закріплений пост з кнопкою «Отримати помічника».

## 2. Запит (бот, 1–2 хв, кнопками)
1. /start → «Хто ти?» — кнопки: Вчитель · ФОП · Водій · HR · SMM · Студент · Інше (текстом).
2. Уточнення (2–3 кнопки/поля): вчитель — предмет, класи; ФОП — сфера (кав'ярня/послуги/торгівля/онлайн), де продаєш.
3. «Що з'їдає найбільше часу?» — вибери до 3 з готового списку під професію (+ «своє»).
4. «Яким ШІ користуєшся?» — ChatGPT · Gemini · Claude · Не знаю (тоді радимо безкоштовний варіант).
5. Ім'я (необов'язково) — лише для привітання. Більше особистих даних не питаємо.

## 3. Що віддаємо (одразу, в боті)
- Повідомлення від Байта: «Олено, твій помічник готовий» + кнопка «Відкрити набір».
- Особиста сторінка набору на сайті з підставленими відповідями (через параметри посилання: предмет, класи, обрані задачі, обраний ШІ) — інструкція вже заповнена, кнопка «Скопіювати», кроки лише для обраного ШІ.
- Файл .txt з інструкцією (для тих, хто з комп'ютера) + PDF «Паспорт помічника» (1–2 сторінки: інструкція, топ-10 команд, картка безпеки) — генеруємо автоматично.
- Відео 60 с «Встав за 2 хвилини» під обраний ШІ (3 ролики на всіх: ChatGPT/Gemini/Claude).
- Кнопка «Налаштував ✅» → бот надсилає перші 3 команди «спробуй зараз».

## 4. Утримання (4 тижні)
- Щовівторка «апгрейд»: новий рівень маршруту (тиждень 1–4), 3 нові команди, 1 нова функція ШІ, 1 попередження. Кнопки «Зробив ✅ / Не вийшло».
- «Не вийшло» → «Спитай Байта»: питання йде в чергу, відповідь до 24 год; найкращі випадки — у Shorts (з дозволу).
- Фінал 4-го тижня: картка-бейдж «Вчитель з ШІ-помічником» з іменем (генерується як OG-картки) — для поширення.

## 5. Ріст
- Отримати набір — після підписки на Telegram-канал (бот перевіряє getChatMember). Рішення власника: вмикати чи ні.
- Рефералка: персональне посилання; 3 друзі → бонус «Pro-команди» (просунуті сценарії, автоматизації).
- «Інше» → нова професія: запит потрапляє в чергу; коли ≥5 запитів на професію — робимо набір (сторінка + Short + стаття). Так аудиторія сама підказує контент.

## 6. Монетизація (пізніше, рішення власника)
- «Помічник Pro» (конектори, автоматизації, документи) — разова оплата.
- «Помічник для команди» — бізнесу (кав'ярня, школа, агенція).
- Спонсор набору професії (напр. сервіс для ФОП) — з позначкою «Партнерський матеріал».

## 7. Метрики
Старти бота → «Налаштував ✅» (активація) → 2-й/4-й тиждень (утримання) → реферали → +підписники TG.
Цілі тесту (2 тижні): 100 стартів, 40% активація, 30% дожили до 2-го тижня.

## 8. Дані й безпека
Зберігаємо лише Telegram id, професію, вибори й прогрес. Без телефонів, пошти, ПІБ. Ніяких токенів у репозиторії.

## Технічно / що потрібно
- Бот: наявний бот ШІкарно + нова гілка сценарію (кнопки, стан у JSON/SQLite).
- Шаблони наборів: Markdown + підстановка з параметрів; PDF і бейдж — Pillow.
- Без платного LLM API на MVP: набори готові під професію + підстановка відповідей. ШІ-генерація під «Інше» — вручну мною в черзі (до 24 год). Платний API — лише якщо власник вирішить.
- MVP: 3 професії (вчитель, ФОП, водій), ~5–7 днів.
