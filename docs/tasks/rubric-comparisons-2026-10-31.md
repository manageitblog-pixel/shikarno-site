# Рубрика порівнянь (рішення власника 31.10: «подобається, як залітають відео порівняння — розвинь»)

Дані: тір-листи — найкращий досмотр (ep21 109% avg view), TikTok органіка 484/906 без реклами.
Правило з 1.11: ≥2 з 4 Shorts на день — з родини порівнянь; не більше 2 однакових форматів поспіль.

## Формати (усі — шаблон Generic, 25–35 с)
1. **Тір-лист Байта #N** (tier: погано/добре/найкраще, 5 рядків) — щодня. Теми в черзі:
   студент, бізнес/ФОП, вчитель, батьки й діти, смартфон-застосунки, безкоштовні ШІ, ШІ для фото, ШІ для відео, ШІ для музики/звуку, браузери з ШІ, ШІ-асистенти в телефоні, ШІ для пошуку роботи, ШІ для здоров'я (найкраще — лікар), ШІ для подорожей.
2. **Платне → безкоштовне** (paidFree: «Не плати за X — є Y») — 3/тиждень. Шаблон є, ще не використовувався.
3. **Битва ШІ: X vs Y** — одне завдання двом ШІ, показ результату + вердикт з аргументом (ChatGPT vs Gemini: рецепт, лист, переклад, фото). 2/тиждень. Лише реальні відповіді, знята сесія.
4. **Тір-лист безпеки** (як ep29 «ШІ-шахраї: що робити») — 2/тиждень: паролі, фото дітей у ШІ, фейкові застосунки «ChatGPT», дипфейки.
5. **Людина vs ШІ** — хто швидше/краще (Байт-скетч) — 1/тиждень.

## Пакування
Назва: «Який ШІ для …? 🤖 Тір-лист Байта #N», «X чи Y: що краще для …?»; обкладинка ShortThumb tag «ТІР-ЛИСТ #N»/«БИТВА ШІ»; TikTok — ті самі, по одному.
Плейлист «Тір-листи Байта» (створити), довгий «Тір-лист ШІ 2026: 50 задач» — кандидат на гайд середи.

## Звіт власнику
Щонеділі (обіцяно 31.10): перегляди YouTube по форматах (порівняння vs інші) + TikTok зі скрінів власника, в бот.

## ШІ для професій (ідея власника 31.10: серія під одну професію; хіти — розвивати, решта поступово)
Етап 1 «розвідка» (1–5.11): по 1 тір-листу на професію — вчитель, бухгалтер/ФОП, SMM/маркетолог, водій/кур'єр, студент (5 задач професії × погано/добре/найкраще).
Етап 2: професія-лідер за 48 год (перегляди, % досмотру, збереження, TikTok) → серія 4–5 відео: тір-лист #2, «Битва ШІ» на задачі професії, «Не плати за це» для професії, «Тір-лист безпеки» (що не вантажити в ШІ), промпти професії. Друга за результатом — серія з 3 відео. Решта — по одному на тиждень.
Наступні в черзі: лікар/медсестра (найкраще — лікар, ШІ лише для паперів), юрист, дизайнер, кухар/кондитер, перукар/б'юті, продавець-маркетплейс, HR, програміст, психолог.
Назва: «ШІ для вчителя: тір-лист 🍎 Що реально економить час», серія з номером «#1/#2»; плейлист на кожну професію-лідера.
Вимоги власника 31.10 (друге повідомлення): формат адаптувати під професію; БЕЗ ВОДИ — лише конкретні інструменти, моделі, функції/скіли (напр. «NotebookLM → аудіоогляд з конспекту», «Gemini Gems для плану уроку», «Claude Skills», «ChatGPT Projects»), кожна функція перевірена на сайті сервісу в день запису; чим більший інтерес до професії — тим глибше (етап 3: розбір конкретних налаштувань, готові скіли/промпти, довге відео-гайд).
Формати під професію: вчитель — «урок за 5 хв» (план → тест → презентація, по кроках з інструментами); бухгалтер/ФОП — «таблиця/документ до/після»; SMM — «пост за 60 с: текст → картинка → відео»; водій/кур'єр — голосові асистенти в авто; студент — «конспект → картки → тест».
