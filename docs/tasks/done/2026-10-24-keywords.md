# Задача: зібрати реальні пошукові запити (Google autocomplete) і переписати SEO під них

Потрібен доступ до suggestqueries.google.com (додано в Settings → Capabilities 23.10; працює в НОВИХ сесіях).
Перевірка: `curl -s "https://suggestqueries.google.com/complete/search?client=firefox&hl=uk&gl=ua&q=chatgpt%20"` → JSON.

## 1. Збір
- Скрипт tools/keywords.py (створити): для кожного seed-запиту — autocomplete з hl=uk, gl=ua; розширення: seed + " " + кожна літера українського алфавіту (а, б, в, г, ґ, д, е, є, ж, з, и, і, ї, й, к, л, м, н, о, п, р, с, т, у, ф, х, ц, ч, ш, щ, ю, я) і питальні префікси («як», «що таке», «чи», «де», «скільки», «навіщо»). Пауза 0.3–0.5 с між запитами, без паралелі.
- Seed: chatgpt; чат gpt; gpt 6; gemini; джеміні; claude; клод ші; штучний інтелект; ші українською; нейромережа; нейромережі для; ші агент; ші для бізнесу; промпти; генерація відео ші; flux; google maps carplay; android auto gemini; meta muse; anthropic; openai; php вразливість; кібербезпека ші; chatgpt безкоштовно; chatgpt україна; gemini українською.
- Результат: docs/keywords.md — таблиця «кластер → запити (дослівно) → наша сторінка або «немає сторінки»». Ранжувати за тим, наскільки часто фраза повторюється в підказках різних seed (проксі популярності; точних обсягів autocomplete не дає — так і написати).

## 2. Застосування (без запитань користувачу)
- Для кожної статті: title, description, перший абзац, один H2 і FAQ — підлаштувати під найближчі реальні формулювання (природно, без переспаму). updated не ставити, якщо зміни лише в SEO-полях; slug НЕ змінювати.
- TAG_INTRO у config.py — доповнити формулюваннями запитів.
- Запити без нашої сторінки → додати в docs/content-backlog.md як теми гайдів/новин (пріоритет за популярністю).
- build.py без помилок → commit → push. Коротко звітувати, що змінено.

Після виконання — перенести файл у docs/tasks/done/.
