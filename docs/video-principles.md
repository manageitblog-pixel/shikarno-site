## 2. Теми (до виробництва)
1. Кожну тему проганяти: `python3 studio/yt/kw.py "<запит>"` → у роботу score ≥ 55 і медіана топ-10 ≥ 1 000. Для нових ніш — допоміжна сесія з vidIQ
   (create_session; кредити 150/міс, бережемо: ~40 лишилось на жовтень).
2. Рубрики й частки (для 2 вірусних слотів; тренд — окремо, щодня): **Безкоштовно #N** 35% · **ШІ-шахраї #N** (безпека родини) 25% · **Байт перевіряє #N** (тір-листи, порівняння, тренди) 25% ·
   **Готові промпти українською #N** 10% (списки під збереження) · великі новини 5% — лише з «що це тобі дає» (решта новин — у тижневий «Новини ШІ за тиждень»).
3. «Байт пробує» / гумор — експеримент: Байт на українських реаліях (теща, ЖЕК, черга, армійський абсурд — без образ).
4. Факти — лише з першоджерел, перевірених сьогодні; суб'єктивні рейтинги підписувати «рейтинг Байта».

## 3. Як робимо Short (5 правил з розборів + наші)
1. **Кадр 0 = суть.** Тір-лист ПОГАНО/ДОБРЕ/НАЙКРАЩЕ (`tier`), ПЛАТНЕ→БЕЗКОШТОВНО (`paidFree`), загроза (hookIcon + `hook`). Жодних інтро, логотипів, «привіт».
2. **Ритм.** Коротка фраза = подія на екрані (картка + звук + рух камери). Новий візуальний елемент кожні 0,5–1,5 с. Довжина 15–25 с (тір-лист), до 40 с для інструкцій.
3. **Рух.** Камера «б'є» між пунктами (наїзд, поворот, спалах), не під час читання; рядки влітають з розмиттям; «найкраще» світиться. Кіно-стиль (Cine) — для трендів/вау-тем, TTS_PACE=hype.
4. **Перекличка** замість монологу, коли можна: Байт + напис-опонент / «Байт-скептик».
5. **Під збереження і петлю:** 5–8 пунктів, кінець повертає до початку; CTA — максимум одна фраза («збережи», питання), без «підписуйся» голосом.
6. **Шахраї:** «як було → як стало → фраза, яку хочеться переслати» + український приклад (дзвінок «з банку», голос родича, OLX-доставка) + «перешли батькам».
7. Субтитри по 2–5 слів завжди (частина дивиться без звуку). Наприкінці — картка соцмереж (Outro).
8. Перевірка: audit_vo (озвучка дослівно), 3–4 кадри з рендеру (обрізання, накладання), тривалість.


### Формат «Промпт → ВИДАВ» (з розбору референсу власника, 28.10) — головний для трендів і «Байт пробує»
1. 0–5 с: на екрані друкується справжній промпт (UI чату, ключові слова підсвічені); голос читає промпт.
2. «І от що він ВИДАВ» — флеш/склейка.
3. 6–15 с: РЕЗУЛЬТАТ на весь екран, без таблиць і субтитрів; голос — 2–3 короткі РЕАКЦІЇ на конкретні деталі («глянь, як…», «а оце…»), не пояснення.
4. Один напис-питання на весь ролик: «Навчити так само?» → у коментарях «так» → промпт у Telegram (воронка в канал).
5. Палітра ролика — чорний + один акцент; без аватара на результаті. Найкраще — живий запис екрана телефоном (власник) і живий голос; інакше — наш UI-макет + TTS у стилі «здивована реакція».
Текст під цей жанр пишемо як розмовну реакцію: ≤ 30 слів, вигуки й паузи, без переліків.

## 4. Упаковка YouTube
- **A/B до 11.11 (погоджено 28.10):** кожен ДРУГИЙ новий ролик — 1 хештег у кінці назви (#ШІ або інструмент); у eps/experiments.json поле `title_hashtag: true/false`; 11.11 порівняти перегляди з пошуку (YT_SEARCH) і загальні.
- **Назва:** ключ/інструмент на початку (з kw.py/vidIQ) + вигода + серія з номером; ≤ 65 знаків; одна емодзі максимум. Мова — українська.
- **Опис:** 1-ше речення = ключовий запит + користь; посилання на статтю сайту; «🎁 PDF 50 промптів — Telegram», TikTok, сайт; дисклеймер про Байта; наприкінці 3 тематичні хештеги + #shorts.
- **Теги:** ключ + 2–3 автопідказки (kw.py `ex`) + англійські ключі vidIQ. **Російських — ніколи** (рішення власника 28.10).
- **Заставка** кожному ролику: Still ShortThumb з `tone` рубрики (free зелений · scam червоний · check бірюзовий · news жовтий · try фіолетовий), `tag` = серія з номером, `headline` ≤ 5 слів з *ключовим словом*, icon, mood → `python3 /home/claude/yt/thumb.py <vid> <jpg>`. Ліміт YouTube ~5 заставок за раз (429) — решту через studio/yt/thumbs_push.py.
- Плейлист рубрики, закріплений коментар-питання, відповіді на перші 20 коментарів.
- Аудит метаданих старих роликів — шаблон studio/yt/audit_2026-10-28.py (з бекапом; не перезаливати).

## 5. TikTok
- Той самий ролик; власнику в бот: відео + опис у блоці копіювання + чистий текст + рекомендований час.
- Хештеги СТАЛІ: `#ші #штучнийінтелект #україна #укртт` + 1 тематичний.
- Публікації з розривом ≥ 3 год, не пачкою. У біо — клікабельне посилання на Telegram.
- Promote — лише для ролика, що довів себе органікою (поширення/збереження), мета «підписники», Україна 18+. Органічні тести позначати в eps/tiktok.json → organic_tests і не змішувати з промотованими.

## 6. Обсяг, структура дня і тренди (рішення власника 28.10: щодня ≥1 тренд + 2–3 вірусні)
**Щодня 3 Shorts** (10:00 / 14:00 / 19:00 Київ = 08/12/17Z), структура:
- **1 ТРЕНД ДНЯ** (обов'язково, слот 10:00 — тренд старіє за години): найгарячіше в ШІ за 24–48 год з українським кутом.
- **2 ВІРУСНІ ФОРМАТИ** (14:00, 19:00): перевірені шаблони — тір-лист / платне→безкоштовне / ШІ-шахраї для родини / готові промпти / гумор Байта.
Тижневий «Новини ШІ за тиждень #N» (неділя), «ШІ за місяць» — 2.11.

**Пошук тренду — щоранку о 07:10Z, ≤ 20 хв, допоміжна сесія (vidIQ + Manifold + вебпошук), шаблон — docs/trend-scan.md:**
1. vidIQ `vidiq_trending_videos` / `vidiq_outliers` (ніша AI, 24–72 год) — що вистрілює на малих каналах;
2. Manifold: TikTok-пошук «ші», «chatgpt», «нейромережа», «ai trend» (UA/EN) за 1–3 дні — звуки/формати, що повторюються;
3. Вебпошук: свіжі релізи/фічі (OpenAI, Google, Anthropic, Meta), вірусні ШІ-тренди (фото-тренди, челенджі), новини про шахраїв в Україні (кіберполіція, банки);
4. kw.py для 2–3 кандидатів → вибір 1 за правилом: свіжість ≤ 48 год + масовість (люди можуть повторити/відчути) + український кут + score/попит.
Тренд, який вимагає вигадок або неперевірених фактів, — не беремо. Результат скану — docs/research/trends-YYYY-MM-DD.md (кандидати + чому обрано).
