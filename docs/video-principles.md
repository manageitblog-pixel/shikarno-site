## 2. Теми (до виробництва)
1. Кожну тему проганяти: `python3 studio/yt/kw.py "<запит>"` → у роботу score ≥ 55 і медіана топ-10 ≥ 1 000. Для нових ніш — допоміжна сесія з vidIQ
   (create_session; кредити 150/міс, бережемо: ~40 лишилось на жовтень).
2. Рубрики й частки: **Безкоштовно #N** 35% · **ШІ-шахраї #N** (безпека родини) 25% · **Байт перевіряє #N** (тір-листи, порівняння, тренди) 25% ·
   **Готові промпти українською #N** 10% (списки під збереження) · великі новини 5% — лише з «що це тобі дає» (решта новин — у тижневий «Новини ШІ за тиждень»).
3. «Байт пробує» / гумор — експеримент: Байт на українських реаліях (теща, ЖЕК, черга, армійський абсурд — без образ).
4. Факти — лише з першоджерел, перевірених сьогодні; суб'єктивні рейтинги підписувати «рейтинг Байта».

## 3. Як робимо Short (5 правил з розборів + наші)
1. **Кадр 0 = суть.** Тір-лист ПОГАНО/ДОБРЕ/НАЙКРАЩЕ (`tier`), ПЛАТНЕ→БЕЗКОШТОВНО (`paidFree`), загроза (hookIcon + `hook`). Жодних інтро, логотипів, «привіт».
2. **Ритм.** Коротка фраза = подія на екрані (картка + звук + рух камери). Новий візуальний елемент кожні 0,5–1,5 с. Довжина 15–25 с (тір-лист), до 40 с для інструкцій.
3. **Рух.** Камера «б'є» між пунктами (наїзд, поворот, спалах), не під час читання; рядки влітають з розмиттям; «найкраще» світиться. Кіно-стиль (Cine) — для трендів/вау-тем, TTS_PACE=hype.
4. **Перекличка** замість монологу, коли можна: Байт + напис-опонент / «Байт-скептик».
5. **Під збереження і петлю:** 5–8 пунктів, кінець повертає до початку; CTA — максимум одна фраза («збережи», питання), без «підписуйся» голосом.
6. **Шахраї:** «як було → як стало → фраза, яку хочеться переслати» + український приклад (дзвінок «з банку», голос родича, OLX-доставка) + «перешли батькам».
7. Субтитри по 2–5 слів завжди (частина дивиться без звуку). Наприкінці — картка соцмереж (Outro).
8. Перевірка: audit_vo (озвучка дослівно), 3–4 кадри з рендеру (обрізання, накладання), тривалість.

## 4. Упаковка YouTube
- **Назва:** ключ/інструмент на початку (з kw.py/vidIQ) + вигода + серія з номером; ≤ 65 знаків; одна емодзі максимум. Мова — українська.
- **Опис:** 1-ше речення = ключовий запит + користь; посилання на статтю сайту; «🎁 PDF 50 промптів — Telegram», TikTok, сайт; дисклеймер про Байта; наприкінці 3 тематичні хештеги + #shorts.
- **Теги:** ключ + 2–3 автопідказки (kw.py `ex`) + англійські ключі vidIQ. **Російських — ніколи** (рішення власника 28.10).
- Плейлист рубрики, закріплений коментар-питання, відповіді на перші 20 коментарів.
- Аудит метаданих старих роликів — шаблон studio/yt/audit_2026-10-28.py (з бекапом; не перезаливати).

- Хештеги СТАЛІ: `#ші #штучнийінтелект #україна #укртт` + 1 тематичний.
