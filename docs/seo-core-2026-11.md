## Правила застосування
- **Назва статті / H1**: ключова фраза на початку (≤ ~90 знаків) + для кого («для ФОП», «для розробників»), коли це не очевидно.
- **Опис** 140–170 знаків: фраза + результат + «безкоштовно/українською», де правда.
- **H2** — під підзапити («Чи є безкоштовно», «Як увімкнути», «Що краще: … чи …»).
- **FAQ** — 3 питання дослівно як у пошуку.
- **Внутрішні посилання**: Short-стаття → повний розбір → хаб тегу.
- **YouTube**: назва Shorts закінчується «#ШІ #shorts»; останній рядок опису — «#shorts #штучнийінтелект #ші #<інструмент>»; для ІТ-роликів інструмент = #claudecode / #codex / #mcp, для бізнесу додатково — #бізнес. Довгі — без #shorts.
- **TikTok**: перший рядок підпису = пошукова фраза кластера; хештеги #штучнийінтелект #аі #укртт + 2 за темою (для ІТ — #програмування, для бізнесу — #бізнес / #фоп).
