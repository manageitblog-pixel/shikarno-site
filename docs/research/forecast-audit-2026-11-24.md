# Аудит прогнозів — Shorts 16–18.11.2026 (кліпи cut6, ~7 днів)

Аналітик даних, 24.11.2026, 19:30Z. Це три кліпи з довгого GNqU-wcz9Ws, у `format_overrides.json` записані як `clip`.

**Дані й застереження**
- **YouTube Analytics запізнюється на 3 дні.** Прямий запит 24.11 віддає дні лише до **21.11**. У `analytics.sqlite` (`daily`, `traffic_daily`, `channel_daily`) теж дані до 21.11. Тому Analytics покриває 7-денне вікно не повністю: RbyuepKjOig — 6 днів із 7, Vp1PPNxtcrI — 5 із 7, bRanUVdt2Pw — 4 із 7. % перегляду й підписки нижче взяті з цих неповних вікон.
- **Факт переглядів за 7 днів** — це публічний `viewCount` із `snap` на день «вихід + 7»: для 16.11 це 23.11, для 17.11 — 24.11. Для 18.11 сьомого дня ще немає, тож узято знімок 24.11, це ≈ 6 днів.
- **Записаного прогнозу немає.** Ні в `ideas.json`, ні в `agent_decisions` для цих роликів його не знайшлося: `ideas.py link` з'явився лише 24.11, і прив'язано тільки ролики від 23.11. Тому прогноз відтворено чинною формулою `ideas.py`. Розрахунок: `stats(today = день виходу)` → медіана формату × `hook_mult` × `length_mult`. Формат `clip` на той момент не мав жодного закритого вікна, тож формула брала fallback `news`. Для порівняння наведено й прогноз старою формулою (length 0.5) з аудиту 22.11.

## 2. Систематичний зсув

- **У цих трьох роликах** прогноз занижений на ~5 % за медіаною, тобто зсув малий. Один промах великий: Vp1PPNxtcrI отримав ×1.94, хоча хук «твоїх + як вимкнути» уже мав ×1.3. Висновків із одного ролика не роблю: роликів із hook 1.3 у вибірці лише 1.
- **Ширший бектест: 40 Shorts за 3–18.11.** Факт для вікон до 15.11 узято з Analytics за повні 7 днів, для 16–18.11 — зі snap.
  - Загалом формула **майже без зсуву**: середній множник ×1.08, медіана «факт / прогноз» 1.05, медіанна |ln|-похибка 0.60.
  - Зсув з'являється, коли вибірку ділити за джерелом медіани, і він протилежний за знаком:
    - **Fallback `news`** (формат без 3 закритих вікон, як кліпи) **занижує**: медіана ×1.26, n = 22.
    - **Власна медіана формату** **завищує**: медіана ×0.72, n = 18. Приклади: tier 10.11 — 391 → 200, prof 9.11 — 162 → 27, free 13.11 — 78 → 30.
  - Друге пов'язане зі спадом стрічки: Shorts каналу за день впали з 356 (12.11) до 43 (21.11), а медіани форматів зібрані з гарячого початку листопада.
- Смуга P25–P75 накрила **15 з 40** (38 %) замість ~50 %. Промахи симетричні: 9 нижче, 16 вище. Отже, смуга вузька, але не зсунута.

**Чому стягування не внесено.**
- Виграш менший за 7 % похибки, а вибірка — 18–40 роликів.
- Головного зсуву (власна медіана ×0.72) воно не прибирає: середній ln-зсув −0.32 → −0.33. Причина цього зсуву — спад стрічки, а не шум малих n.
- Стягування також знизило б prior tier на дошці (1.0 → ~0.92) і змінило рейтинг ідей. Таку зміну варто робити на ширших даних.

Рішення записано в журнал: `ops.py decide`, type `policy`, status `proposed`, id `401e6175-4c67-4b28-bbaa-8fa5115d158c`. Повторна перевірка — **01.12**. На той час у `stats()` з'явиться clip із n ≥ 3, а для бектесту закриється ще ~10 вікон.

Дрібниця в коді: docstring `ideas.py` досі каже «length: 35–45 ×0.6, >45 ×0.5», хоча код рахує 0.85 / 0.8.
