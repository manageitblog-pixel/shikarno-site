# Пов'язане відео (Related video) для Shorts 31.10–29.11 — таблиця «Short → довге»

Підготував: SEO YouTube, 22.11.2026. Підстава: docs/org/strategy.md §5 п.4 і §6 п.1 (E1 `exp-2026-11-22-yt-related-cta`).
Навіщо: зі стрічки Shorts у довгі перейшов 21 перегляд з 8 061, а години для YPP рахуються лише з довгих. Посилання «пов'язане відео» — кнопка під Short, яка веде на довге.
API YouTube цього поля не має, тому ставиш вручну.

## Як поставити

Офіційна довідка: [Add a related video to your YouTube Shorts](https://support.google.com/youtube/answer/14075157) (укр.: «Пов'язане відео»). Перевірено 22.11.2026.
Умови з довідки: потрібен **доступ до розширених функцій** каналу; вибране довге має бути **«Для всіх» або «Не для всіх»** і відповідати правилам спільноти. Тому ep78/ep81/ep82 (заплановані) можна налаштувати вже зараз — обмеження стосується довгого, а не Short.

### На комп'ютері (офіційні кроки, Студія YouTube)
1. Відкрий **studio.youtube.com** і ввійди.
2. У меню ліворуч вибери **«Контент»** → вкладка **«Shorts»**.
3. Клацни на Short, який редагуєш (відкриються «Відомості про відео»).
4. У полі **«Пов'язане відео»** вибери довге зі свого каналу (є пошук за назвою).
5. Натисни **«ЗБЕРЕГТИ»** вгорі праворуч. Повтори для наступного Short (≈30 с на один).

### На телефоні
Довідка Google описує **лише Студію в браузері**. Кроків для застосунку YouTube Studio там немає, і незалежні гайди (vidIQ) теж пишуть, що це поле є тільки на комп'ютері. Тому з телефона так:
1. Відкрий **Chrome** (або Safari) і перейди на **studio.youtube.com** (не в застосунку).
2. Меню браузера **⋮** → увімкни **«Версія для ПК»** (Safari: **aA** → **«Запит версії для комп'ютера»**).
3. **«Контент»** → **«Shorts»** → натисни потрібний Short.
4. **«Пов'язане відео»** → вибери довге → **«ЗБЕРЕГТИ»**.
5. Якщо в застосунку YouTube Studio під час завантаження нового Short ти бачиш пункт «Пов'язане відео» — можна ставити і там, але для вже опублікованих Shorts надійний шлях — кроки 1–4.
