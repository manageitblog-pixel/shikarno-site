## 3 висновки для наших TikTok

1. **Хук = категорична заява текстом + голос із 0-ї секунди.** Усі аномалії стартують без інтро: факт-загроза
   («виявили критичну вразливість»), впізнавана ситуація («коли вирішив культурно спілкуватися з GPT») або готовий результат ШІ
   на екрані (№1, №6). Для нас: перший кадр — результат/вердикт Байта великим текстом, а не привітання.
2. **Тривалість — дві зони: 10–40 с (скетч, луп, гаджет-демо) або 65–180 с (розбір із результатом).** Довгі вистрілюють лише
   коли показують, що ШІ реально зробив (№1, №2, №4); середня зона 45–60 с без «вау-результату» у @ai_sashka — 1.8–2.4K.
   Для нас: Short/TikTok 25–40 с; окрема TikTok-версія 60–90 с лише для «тест/розбір з результатом».
3. **Підпис = пошукові запити, як їх набирають.** @ai_sashka пише в підпис 5–7 варіантів запиту («ai для відео, безкоштовні ai
   додатки для відео, ші для музики…») + #creatorsearchinsights — і ці ролики мають 7 % збережень проти <1 % в «історій».
   Для нас: перший рядок підпису — запит («безкоштовний ші для …», «chatgpt українською …»), 3–5 варіантів «ші/ai/аі», хештеги
   #штучнийінтелект #ші #нейромережі.
