## Висновки

- Люди гуглять «chatgpt»/«чат gpt», «gemini»/«джеміні»/«геміні», «claude»/«клод ші» — латиницею і кирилицею. У текстах варто природно згадувати обидва написання.
- Найчастіші наміри: *що це*, *як користуватися*, *безкоштовно*, *українською*, *чи … чи …* (порівняння), *скільки коштує*, *як відключити / скасувати підписку*.
- Найширше (у підказках найбільшої кількості seed) — практичні задачі без наших сторінок: презентації, відео з фото, музика й пісні, картинки, озвучка тексту українською. Вони пішли в `docs/content-backlog.md` (розділ «З autocomplete»).
- Для «php вразливість» Google не дав жодної підказки, для «кібербезпека ші» — три загальні. Безпекові статті ранжуються за назвами конкретних атак (PHP2Shell, CVE), а не за загальними запитами.
- «Як читається claude / gemini / anthropic / openai» — частий запит; відповідь додано у FAQ відповідних статей.
- Порівняння в підказках формулюють через «чи»: «chatgpt чи gemini», «claude чи chatgpt» (за Ubersuggest обсяг мають «vs»-формули) — у статті є обидві.
