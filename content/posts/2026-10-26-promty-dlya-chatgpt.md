Промпти для ChatGPT — це різниця між «ШІ видає воду» і «ШІ зекономив мені годину». Нижче — що таке промпт, проста формула з п'яти частин і 24 готові промпти українською для життя, роботи, навчання й бізнесу. Копіюй, заміни текст у [квадратних дужках] — і працює в ChatGPT, Gemini чи Claude.

## Що таке промпт (і чому «промпти», а не «промти»)

Промпт (від англ. prompt — «підказка, спонукання») — це будь-який текст, яким ти ставиш завдання ШІ-асистенту: питання, інструкція, шматок документа з проханням його скоротити. Промптинг — уміння формулювати ці завдання так, щоб відповідь була корисною з першої-другої спроби.

Чому це важливо: модель не читає твої думки. Вона не знає, що ти ФОП із кав'ярнею в Житомирі, що лист піде директору, а не другові, і що тобі треба 5 пунктів, а не есе. Anthropic у документації для Claude радить уявляти асистента як блискучого, але нового працівника, який ще не знає твоїх правил. OpenAI у довідці для ChatGPT каже те саме іншими словами: будь чітким і конкретним, давай достатньо контексту.

## Як писати промпти для ChatGPT: формула з 5 частин

**Роль · задача · контекст · формат · обмеження.**

| Частина | Питання | Приклад |
|---|---|---|
| Роль | Ким має бути ШІ? | «Ти — досвідчений бухгалтер для ФОП» |
| Задача | Що саме зробити? | «Поясни, як подати декларацію» |
| Контекст | Для кого, навіщо, які деталі? | «ФОП 3 групи, перший рік, без працівників» |
| Формат | У якому вигляді? | «Покроковий список, до 10 пунктів» |
| Обмеження | Чого уникати, тон, мова? | «Простими словами, без канцеляриту, українською» |

Шаблон, який можна вставляти будь-куди:

```
Ти — [роль]. Зроби [задача] для [кого / навіщо].
Контекст: [2–3 речення деталей].
Формат: [список / таблиця / лист / обсяг у словах].
Обмеження: [тон, мова, чого не робити].
```

Не обов'язково заповнювати всі п'ять частин. Для простого питання вистачить задачі й формату. Але що важливіший результат, то більше контексту варто дати.

Три прийоми, які помітно покращують відповідь:

- **Поясни «навіщо».** Не «коротко», а «коротко, бо читатимуть з телефона». Anthropic прямо пише, що пояснення мотивації допомагає моделі точніше влучити в ціль.
- **Дай приклад.** Встав абзац тексту, стиль якого тобі подобається, і напиши «пиши в такому стилі». Приклади — один із найнадійніших способів задати тон і формат.
- **Довгий текст — угорі.** Якщо даєш документ, спершу встав його, а інструкцію напиши після нього.

## 24 готові промпти українською

### Для життя

**1. Меню на тиждень**
```
Склади меню на 7 днів для сім'ї з [кількість] людей, бюджет [сума] грн на тиждень. Продукти — зі звичайного українського супермаркету. Додай список покупок, згрупований за відділами.
```

**2. Скарга або офіційний лист**
```
Допоможи написати заяву до [ОСББ / сервісу / магазину] щодо [проблема]. Факти: [дати, суми, що сталося]. Тон — спокійний і твердий. Вкажи, чого я вимагаю, і строк відповіді.
```

**3. Подорож**
```
Сплануй поїздку в [місто] на [кількість] дні для [хто їде]. Бюджет [сума]. Розпиши по днях: що подивитися, де поїсти недорого, як пересуватися. Познач, що варто перевірити перед поїздкою.
```

**4. Розібратися в договорі**
```
Ось текст договору: [текст]. Поясни простими словами, які в мене обов'язки, штрафи й умови розірвання. Окремо — пункти, які варто уточнити в юриста.
```

**5. Привітання**
```
Напиши тепле привітання з [свято] для [кому, хто він тобі], 4–5 речень. Згадай [спільний спогад або риса людини]. Без банальностей на кшталт «щастя, здоров'я».
```

**6. Сімейний бюджет**
```
Ось мої витрати за місяць: [список]. Згрупуй їх у категорії, покажи таблицею, де я витрачаю найбільше, і дай 3 реалістичні способи зекономити [сума] грн.
```

### Для роботи

**7. Діловий лист**
```
Ти — досвідчений менеджер. Напиши лист [кому] з проханням [що]. Тон — ввічливий, але конкретний. До 120 слів. Додай 2 варіанти теми листа.
```

**8. Підсумок зустрічі**
```
Ось нотатки зустрічі: [текст]. Зроби підсумок: ухвалені рішення, задачі з відповідальними й строками, відкриті питання. Формат — список.
```

**9. Резюме під вакансію**
```
Ось моє резюме: [текст] і вакансія: [текст]. Перепиши розділ «Досвід» так, щоб підкреслити відповідність вакансії. Не вигадуй фактів, яких немає в резюме.
```

**10. Підготовка до співбесіди**
```
Я йду на співбесіду на посаду [посада] в [тип компанії]. Дай 10 імовірних питань і коротку структуру сильної відповіді на кожне. Потім влаштуй мені пробну співбесіду: питай по одному.
```

**11. Звіт для керівника**
```
Ось що я зробив за тиждень: [список]. Перетвори це на короткий звіт для керівника: результати, цифри, проблеми, план на наступний тиждень. До 150 слів.
```

**12. Перевірка тексту**
```
Перевір текст на помилки й стиль. Виправ, а окремо списком поясни головні правки: [текст].
```

### Для навчання

**13. Пояснення простими словами**
```
Поясни [тема] так, ніби мені 15 років. Використай один приклад із життя. Потім дай 3 питання для самоперевірки, відповіді — в кінці.
```

**14. План вивчення навички**
```
Склади план вивчення [навичка] за 4 тижні по 30 хвилин на день: що вчити, практичне завдання на кожен день, безкоштовні ресурси.
```

**15. Тренер з англійської**
```
Ти — викладач англійської. Мій рівень — [A2/B1/B2]. Поговори зі мною англійською на тему [тема]. Після кожної моєї відповіді коротко виправ помилки українською і постав наступне питання.
```

**16. Конспект**
```
Ось текст лекції або статті: [текст]. Зроби конспект: 5 головних думок, ключові терміни з визначеннями, 3 питання, які можуть бути на іспиті.
```

**17. Перевірка розуміння**
```
Я вивчаю [тема]. Перевір мене: постав 5 питань від простого до складного, по одному. Не підказуй відповідь, доки я не спробую.
```

**18. Ідеї для уроку (вчителям)**
```
Ти — методист. Запропонуй 3 ідеї інтерактивного уроку на тему [тема] для [клас]. Для кожної: мета, хід уроку на 45 хвилин, що підготувати.
```

### Для бізнесу

**19. Опис товару**
```
Напиши опис товару [назва] для інтернет-магазину: 3 переваги, характеристики списком, для кого підійде. Без перебільшень і вигаданих характеристик. До 150 слів.
```

**20. Відповідь на скаргу клієнта**
```
Ти — менеджер підтримки. Ось скарга клієнта: [текст]. Напиши відповідь: визнай проблему, запропонуй рішення [яке], без шаблонних фраз. До 100 слів.
```

**21. Пост для соцмереж**
```
Ти — SMM-фахівець. Напиши пост для [Instagram / Facebook / Telegram] про [продукт або подію] для аудиторії [хто]. Сильний перший рядок, 3 короткі абзаци, заклик до дії.
```

**22. Контент-план**
```
Склади контент-план на 2 тижні для [бізнес] у [соцмережа]: дата, тема, формат (пост, сторіс, відео), мета. Формат — таблиця.
```

**23. Комерційна пропозиція**
```
Ти — B2B-продавець. Напиши комерційну пропозицію для [клієнт] на [послуга]: проблема клієнта, рішення, результат, ціна [сума], наступний крок. До 200 слів.
```

**24. Відповіді на заперечення**
```
Наш продукт: [опис]. Склади відповіді на 5 типових заперечень: «дорого», «подумаю», «у нас уже є», «немає часу», «не впевнений». Тон — дружній, без тиску.
```

## Що робити, якщо ChatGPT відповів погано

Перша відповідь — чернетка, а не вирок. OpenAI радить саме ітеративний підхід: подивився на результат, уточнив формулювання, додав контекст. Ось фрази, які працюють:

- **«Коротше, вдвічі»** або **«до 50 слів»** — якщо вийшла вода.
- **«Менш офіційно, як другу»** — якщо звучить як довідка з ЖЕКу.
- **«Задай мені 3 уточнювальні питання, перш ніж відповідати»** — коли не знаєш, який контекст потрібен.
- **«Що в цій відповіді може бути неправдою?»** — простий фільтр для фактів.
- **«Дай 3 різні варіанти»** — коли не подобається жоден.
- **«Ось приклад, як має бути: [текст]»** — найшвидший спосіб пояснити стиль.

Якщо чат «поплив» після довгої розмови, відкрий новий і встав туди підсумок: «Ось що ми з'ясували: …». Свіжий контекст часто дає кращий результат.

А якщо однакові побажання повторюєш щоразу («відповідай українською», «без вступів»), запиши їх у **Custom instructions** (Налаштування → Персоналізація). За довідкою OpenAI, вони доступні на всіх тарифах, а на безкоштовному можна зберегти до 1500 знаків. Інструкції діють для всіх чатів.

## Типові помилки в промптах

- **Занадто загально.** «Напиши пост» → середній текст ні про що. Додай аудиторію, мету й формат.
- **Без контексту.** ШІ не знає твій бізнес, твого керівника чи твій рівень. Дай 2–3 речення.
- **Десять задач в одному повідомленні.** Розбий на кроки: спершу план, потім кожен пункт.
- **Віра на слово.** ChatGPT може впевнено вигадати цифру, закон чи цитату. Усе, що піде в документ, перевіряй за першоджерелом.
- **Прохання «не роби X» без «роби Y».** Краще писати, що потрібно, а не лише чого уникати: «пиши короткими реченнями» замість «не пиши довго».

## Приватність: що не вставляти в промпт

Промпт — це текст, який ти відправляєш компанії. Тому:

- **Не вставляй** паролі, номери карток, паспортні дані, медичні документи чужих людей і комерційну таємницю. Детальніше — у статті [що не давати ШІ](/novyny/shcho-ne-davaty-shi/).
- **Тимчасовий чат.** За даними OpenAI, такий чат не з'являється в історії й не використовується для покращення моделей, але копія може зберігатися до 30 днів з міркувань безпеки.
- **Вимкни навчання на своїх чатах:** Налаштування → Data controls → «Improve the model for everyone». Це не видаляє вже наявні чати.
- **Пам'ять.** ChatGPT може запам'ятовувати деталі з розмов. Як це перевірити й очистити — у гайді [як видалити пам'ять ChatGPT](/novyny/chatgpt-pamyat-yak-vydalyty/).

## Ці промпти працюють не лише в ChatGPT

Формула універсальна: ті самі шаблони можна вставити в Gemini чи Claude. Відповіді будуть різні за стилем, тож для важливих задач варто порівняти два асистенти. Claude, до речі, теж можна спробувати без оплати — ось [як користуватися Claude безкоштовно](/novyny/claude-bezkoshtovno/). Не знаєш, що обрати? Глянь [порівняння ChatGPT, Gemini і Claude](/novyny/chatgpt-vs-gemini-vs-claude/). А для картинок — окремі [промпти для фото в українському стилі](/novyny/foto-v-ukrainskomu-styli-shi/).
