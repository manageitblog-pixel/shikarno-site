**Claude Code** — одна з найпопулярніших тем серед розробників: лише «claude code» в українському Google шукають десятки тисяч разів на місяць. Розбираємо, що це і чи потрібен він тобі.

## Що таке Claude Code

Це **ШІ-агент для програмування** від Anthropic. На відміну від звичайного чату, де ти копіюєш код туди-сюди, Claude Code **працює прямо з твоїм проєктом**:

- читає файли і пояснює, як влаштований код;
- пише нові функції і змінює існуючі;
- виправляє помилки, пише й запускає тести;
- виконує команди в терміналі (з твого дозволу);
- готує коміти й описи змін.

Задачу ставиш звичайною мовою — наприклад: «додай перевірку email у форму реєстрації і напиши тести».

## Де працює

- **Термінал** — класичний варіант для розробників.
- **Десктопний застосунок** Claude.
- **Редактори коду:** розширення для VS Code і JetBrains.
- **З телефона:** задачі можна делегувати віддалено через мобільний застосунок Claude.

Інструкція з встановлення — в офіційній документації Anthropic.

## Скільки коштує

| Варіант | Ціна (США) | Для кого |
|---|---|---|
| Claude Pro | $20/міс | спробувати, невеликі проєкти |
| Claude Max 5x | $100/міс | щоденна інтенсивна розробка |
| Claude Max 20x | $200/міс | робота з Claude Code цілий день |
| API | оплата за токени | команди й автоматизація |

Claude Code входить у підписки Pro і Max без доплати. Чим більший тариф, тим більше використання. Які моделі під капотом і чим вони відрізняються — у нашому розборі [Claude AI 5.5: Opus, Sonnet і Haiku](/novyny/claude-5-5-opus-sonnet-haiku/).

## Кому підійде

- **Розробникам** — прискорити рутину: тести, рефакторинг, документація, міграції.
- **Стартапам і фрілансерам** — швидше доводити прототипи до робочого стану.
- **Тим, хто вчиться** — розбиратися в чужому коді з поясненнями.

## Ризики і правила

- **Тримай проєкт у Git** — так будь-яку зміну агента легко переглянути й відкотити.
- **Переглядай зміни** перед комітом: агент може помилитися або зробити більше, ніж просили.
- **Обережно з дозволами:** не давай агенту доступу до продакшн-серверів і секретів без потреби.
- **Ліміти:** великі задачі швидко «з'їдають» ліміти тарифу — розбивай їх на менші.

Чому контроль за агентами — не формальність, добре видно з кейсу, коли [агенти OpenAI вимкнули нагляд за собою](/novyny/agenty-openai-nagliad/). А загальні правила — у гайді [ШІ-агенти простими словами](/novyny/shi-agenty-gid/).
